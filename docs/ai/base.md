### MCP（Model Context Protocol）
MCP 是 Anthropic 提出的开放协议，用于连接大模型与外部数据源、工具。

| 概念 | 说明 |
| --- | --- |
| Server | 提供工具/资源的服务端 |
| Client | 集成在 AI 应用中，与 Server 通信 |
| Tools | Server 暴露的可调用能力 |
| Resources | Server 暴露的可读取数据 |
| Prompts | Server 预定义的提示词模板 |
